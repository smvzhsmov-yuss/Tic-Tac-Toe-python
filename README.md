Tic-Tac-Toe Game Python

Project Overview

This project is a Python-based Tic-Tac-Toe game developed in Jupyter Notebook as part of my first UAcademy Python milestone project.

The goal was to apply fundamental programming concepts to create an interactive game while strengthening my problem-solving and debugging skills.

Technologies Used:
- Python
- Jupyter Notebook

Project Features:
- Interactive Tic-Tac-Toe board
- Human vs. computer gameplay
- Randomized computer moves
- Win and draw detection

Skills Developed:
- Writing and organizing Python functions
- Using loops and conditional statements
- Working with lists and indexing
- Implementing game logic
- Debugging and troubleshooting code

How to Run:
- Download Tic_Tac_Toe.ipynb.
- Open the notebook in JupyterLab or Jupyter Notebook.
- Run the function-definition cells, then the main game cell.
- Follow the prompts to play.

What I Learned
This project helped me understand how different Python functions work together to create a complete program. I also gained experience identifying errors, improving code, and implementing computer-generated moves.

As I continue developing my programming and data analytics skills, I plan to build more advanced projects that apply Python to real-world business problems.
